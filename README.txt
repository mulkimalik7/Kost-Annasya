KOST ANNAYSA
============

Deskripsi
---------
Website ini menampilkan profil Kost Annaysa, fasilitas, pilihan kamar, harga,
peraturan, dan informasi kontak.

Teknologi
---------
- HTML untuk struktur halaman.
- CSS untuk tampilan dan layout responsif.
- JavaScript untuk navigasi hamburger, penghitung karakter, dan formulir WhatsApp.

Urutan bagian halaman
---------------------
1. Beranda
2. Tentang
3. Fasilitas
4. Kamar
5. Harga
6. Peraturan
7. Kontak

Struktur folder
---------------
- index.html
- css/style.css
- js/script.js
- assets/icons/
- assets/images/bangunan/
- assets/images/fasilitas/
- assets/images/kamar/

Cara menjalankan
----------------
1. Buka folder proyek Kost Annaysa.
2. Buka index.html di browser.

Seluruh gambar yang digunakan berada di dalam folder assets/images.
